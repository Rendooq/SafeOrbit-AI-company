За розкладом у GitHub Actions

Додайте шаблон до .github/workflows/safeorbit-checkout.yml у своєму репозиторії. У секретах GitHub Actions збережіть ключ як SAFEORBIT_CHECK_KEY, а заповнену конфігурацію як SAFEORBIT_CHECKOUT_CONFIG. У вкладці Actions запустіть першу перевірку. На основній гілці наступні запуски заплановані кожні 30 хвилин.

На своєму комп’ютері або сервері

Установіть Playwright і Chromium, збережіть конфігурацію як checkout.json та передайте ключ через SAFEORBIT_CHECK_KEY. Запустіть node checkout-check.mjs checkout.json. Для постійних перевірок додайте --watch і задайте intervalMinutes.

Завантажити сценарій ↓
